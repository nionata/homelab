# BART Tender

Like a Bar tender, but for the BART.

## What is this?

BART is a great way to get around the bay area. Regulars ride the same route often. The [eta](https://www.bart.gov/schedules/eta/GLEN) page on the BART website does this effectively. This project ports this into a physical display box.

## How?

Displays a configurable list of lines (ie. red to millbrae) by when the next train is and the one after that. That's it. Your favorite lines constantly displaying status. Powered by a networked embedded device and LCD panel.
