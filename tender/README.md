# BART Tender

Like a Bar tender, but for the BART.

## What is this?

BART is a great way to get around the bay area. Regulars ride the same route often. It should be easy to see the status of the same route(s) quickly.

## How?

Displays a configurable list of lines (ie. red to millbrae) by when the next train is and the one after that. That's it. Your favorite lines constantly displaying status.
